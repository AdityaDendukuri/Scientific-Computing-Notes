36  Python and NumPy Primer

This section summarizes the NumPy array conventions, linear-algebra operations, and indexing idioms used throughout the computational examples in these notes.

36.1 Arrays and Basic Operations

NoteDefinition: NumPy Arrays

The ndarray is the fundamental structure.

  • Creation: np.array([1, 2]), np.zeros((m, n)), np.random.randn(m, n).

  • Indexing: 0-indexed. A[i, j] for entries, A[i, :] for rows, and A[:, j] for columns.

TipRemark

(Shapes and one-dimensional arrays) A.shape returns (m, n). A 1D array has shape (n,), which is not equivalent to a column vector (n, 1). These one-dimensional arrays can behave differently from column arrays under broadcasting. Use x[:, None] or x.reshape(-1, 1) to convert to 2D.

WarningExercise

  1. Create \(4 \times 4\) identity matrix. Verify shape and dtype.

  2. Extract row 2 and column 3 from a random \(3 \times 3\) \(\bA\).

  3. Compare A @ x for x.shape == (3,) and x.shape == (3,1). Record the output shape in each case, then explain why the two representations behave differently under broadcasting.

36.2 Linear Algebra Operations

The core routines in numpy.linalg provide access to standard BLAS and LAPACK implementations:

TipRemark

(Vectorization and performance) Explicit for loops in Python are slow. Push heavy lifting into NumPy/BLAS routines by vectorizing operations. For example, use A @ B instead of triple-nested loops.

TipRemark

(Linear solve versus inversion) np.linalg.solve(A, b) is faster and more stable than np.linalg.inv(A) @ b. Explicit inversion is almost never desirable in scientific computation.

TipRemark

(Computed equality) For computed floating-point quantities, compare the error with a tolerance appropriate to their scale. Functions such as np.allclose and np.isclose perform tolerance tests. Their default tolerances do not establish mathematical equality or certify accuracy for every problem. Exact equality is appropriate for integers, booleans, and deliberately exact structural checks.

TipRemark

(Sparse matrices) Large discretized PDE and graph problems should usually use scipy.sparse, not dense NumPy arrays. Use scipy.sparse.linalg for sparse solves, eigenvalue computations, CG, and GMRES.

WarningExercise

  1. Solve a \(2 \times 2\) system and verify the residual \(\|\bA\bx - \bb\|\).

  2. Profile solve vs inv @ b for \(n=1000\).

  3. Compare np.linalg.eig and np.linalg.eigh (optimized for symmetric matrices).

WarningExercise

For a \(3\times3\) matrix, form an approximation x with shape (3,1) and a right-hand side b with shape (3,). Predict the shape of b - A @ x before evaluating it. Explain why that array is not the residual vector you intended. Make the shapes consistent and recompute the residual.

36.3 Key Idioms

  • Element-wise: * and ** are entry-wise. Matrix powers use np.linalg.matrix\_power.

  • Broadcasting: Automatic dimension expansion. For A.shape == (m,n) and v.shape == (n,), A * v scales columns by the entries of v. To scale rows by a vector of length m, use A * v[:,None].

  • Aliases, Views, Copies: B = A makes a second name for the same array. Slices are usually views. Use B = A.copy() for independent data.

  • Sparse construction: The scipy.sparse module provides diags for banded matrices and csr\_matrix for compressed sparse row storage.

WarningExercise

  1. Let \(\bA = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}\). Compare A * A and A @ A.

  2. Demonstrate the ``view pitfall’’ by modifying a slice of a matrix.

  3. Use broadcasting to perform diagonal scaling \(\bA\bD\) without constructing \(\bD = \text{diag}(d)\).

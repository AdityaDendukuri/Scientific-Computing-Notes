3  Matrix Norms and Condition Numbers

A matrix changes the size of a vector. To bound the effect of an error in the input, we need the largest possible ratio between output length and input length. This ratio defines the induced matrix norm. We distinguish it from the Frobenius norm, which measures the entries of a matrix as data.

An invertible matrix may stretch one direction and compress another. Solving a system reverses that action. The condition number compares the largest stretch with the smallest and will explain why a small residual can accompany a large solution error.

3.1 Induced Matrix Norms

NoteDefinition: Induced Operator Norm

Let \(\|\cdot\|_{\mathrm{in}}\) be a norm on \(\fR^n\) and let \(\|\cdot\|_{\mathrm{out}}\) be a norm on \(\fR^m\). For \(\bA\in\fR^{m\times n}\), the induced operator norm is \[ \begin{align} \|\bA\| =\sup_{\bx\neq\bzero} \frac{\|\bA\bx\|_{\mathrm{out}}}{\|\bx\|_{\mathrm{in}}} =\max_{\|\bx\|_{\mathrm{in}}=1}\|\bA\bx\|_{\mathrm{out}}. \end{align} \] When the same \(p\)-norm is used in the domain and range, we write \(\|\bA\|_p\).

WarningExercise

For \(\bA=\begin{pmatrix}1&1\\1&1\end{pmatrix}\), compare \(\|\bA\bx\|_2/\|\bx\|_2\) for \(\bx=(1,1)^T\) and \(\bx=(1,-1)^T\). Find the largest ratio by expanding \(\|\bA\bx\|_2^2\). Explain why neither one test vector nor the largest matrix entry determines the induced norm.

The quotient is unchanged when \(\bx\) is rescaled, so only directions matter. Restricting to the unit sphere removes the irrelevant magnitude. In finite dimensions the unit sphere is compact and the objective is continuous, so the maximum is attained.

NoteTheorem: Fundamental Properties of Induced Norms

For compatible matrices and vectors,

  1. Consistency: \(\|\bA\bx\|\leq\|\bA\|\,\|\bx\|\).

  2. Submultiplicativity: \(\|\bA\bB\|\leq\|\bA\|\,\|\bB\|\).

  3. Identity: \(\|\bI\|=1\).

  4. Norm axioms: the induced norm is positive definite, absolutely homogeneous, and satisfies the triangle inequality.

TipProof

We verify each assertion from the definition. All norms on intermediate vector spaces must be compatible, so the output norm for \(\bB\) is the input norm for \(\bA\).

  1. If \(\bx=\bzero\), the inequality reads \(0\leq0\). Otherwise the quotient \(\|\bA\bx\|/\|\bx\|\) is one of the values bounded by the supremum defining \(\|\bA\|\). Multiplication by \(\|\bx\|>0\) gives the result.

  2. For any unit vector \(\bx\), apply consistency twice: \[ \begin{align} \|\bA\bB\bx\|\leq\|\bA\|\|\bB\bx\| \leq\|\bA\|\|\bB\|\|\bx\|=\|\bA\|\|\bB\|. \end{align} \] The right side does not depend on \(\bx\). Taking the maximum over unit inputs proves submultiplicativity.

  3. When the same norm is used on input and output, \(\|\bI\bx\|/\|\bx\|=1\) for every nonzero input. Its supremum is therefore one.

  4. Every quotient is nonnegative. If \(\bA=\bzero\), all quotients vanish. Conversely, if \(\|\bA\|=0\), consistency gives \(\bA\be_j=\bzero\) for each coordinate vector. These are exactly the columns of \(\bA\), so \(\bA=\bzero\).

  5. For \(\|\bx\|=1\), \(\|\alpha\bA\bx\|=|\alpha|\|\bA\bx\|\). Taking maxima yields \(\|\alpha\bA\|=|\alpha|\|\bA\|\).

  6. For every unit input, \[ \begin{align} \|(\bA+\bB)\bx\|\leq\|\bA\bx\|+\|\bB\bx\| \leq\|\bA\|+\|\bB\|. \end{align} \] Taking the maximum gives \(\|\bA+\bB\|\leq\|\bA\|+\|\bB\|\).

WarningExercise

Submultiplicativity from amplification. Prove \(\|\bA_1\cdots\bA_k\|\leq\prod_{j=1}^k\|\bA_j\|\). Explain why this bound may be conservative when the direction of greatest stretch for one factor is not mapped into the direction of greatest stretch for the next.

NoteExample

For the diagonal matrix \[ \begin{align} \bD=\begin{pmatrix}4&0\\0&1/2\end{pmatrix}, \end{align} \] the Euclidean unit circle is sent to an ellipse with semiaxis lengths \(4\) and \(1/2\). Hence \(\|\bD\|_2=4\). The norm records the greatest stretch, not the average stretch and not the largest entry by convention. In this example those quantities happen to agree because the coordinate axes are the stretching directions.

NoteTheorem: The Induced \(1\)- and Infinity Norms

For \(\bA=(a_{ij})\in\fR^{m\times n}\), \[ \begin{align} \|\bA\|_1 &=\max_{1\leq j\leq n}\sum_{i=1}^m|a_{ij}|, & \|\bA\|_\infty &=\max_{1\leq i\leq m}\sum_{j=1}^n|a_{ij}|. \end{align} \] Thus the induced \(1\)-norm is the largest absolute column sum, while the induced infinity norm is the largest absolute row sum.

TipProof

For each formula we need an upper bound for every input and an input that attains it.

Let \(C=\max_j\sum_i|a_{ij}|\), the largest absolute column sum. Expanding each output entry and using the triangle inequality gives \[ \begin{align} \|\bA\bx\|_1 &=\sum_{i=1}^m\left|\sum_{j=1}^na_{ij}x_j\right|\\ &\leq\sum_{i=1}^m\sum_{j=1}^n|a_{ij}||x_j|\\ &=\sum_{j=1}^n|x_j|\left(\sum_{i=1}^m|a_{ij}|\right) \leq C\sum_{j=1}^n|x_j|=C\|\bx\|_1. \end{align} \] The interchange of sums is legitimate because both are finite. For unit inputs this proves \(\|\bA\|_1\leq C\).

Choose a column \(j_*\) attaining \(C\). The input \(\be_{j_*}\) has \(1\)-norm one, and multiplying by it selects that column. Therefore \[ \begin{align} \|\bA\be_{j_*}\|_1=\sum_i|a_{ij_*}|=C. \end{align} \] The maximum is at least \(C\), so the upper bound is exact.

For the infinity norm, put \(R=\max_i\sum_j|a_{ij}|\). For any input, \[ \begin{align} |(\bA\bx)_i| &\leq\sum_j|a_{ij}||x_j| \leq\left(\sum_j|a_{ij}|\right)\|\bx\|_\infty \leq R\|\bx\|_\infty. \end{align} \] This holds for every row, so taking their maximum gives \(\|\bA\|_\infty\leq R\).

Choose a maximizing row \(i_*\). Set \(x_j=1\) when \(a_{i_*j}\geq0\) and \(x_j=-1\) when \(a_{i_*j}<0\). In particular choose \(1\) for a zero entry, so the input has infinity norm one even for the zero matrix. Each product in that row is \(a_{i_*j}x_j=|a_{i_*j}|\). Thus \((\bA\bx)_{i_*}=R\), proving attainment and the second formula.

WarningExercise

Three induced norms. For \[ \begin{align} \bA=\begin{pmatrix}1&-2\\3&4\end{pmatrix}, \end{align} \] compute \(\|\bA\|_1\) and \(\|\bA\|_\infty\). Estimate \(\|\bA\|_2\) from below by testing at least four unit vectors and from above using \(\|\bA\|_F\).

NoteDefinition: The Induced Euclidean Norm

The induced Euclidean norm is \[ \begin{align} \|\bA\|_2 =\max_{\|\bx\|_2=1}\|\bA\bx\|_2. \end{align} \] Equivalently, \[ \begin{align} \|\bA\|_2^2 =\max_{\|\bx\|_2=1}\bx^T\bA^T\bA\bx. \end{align} \]

The second expression follows by squaring the output norm. It already shows why \(\bA^T\bA\) appears in questions about Euclidean amplification. Once the singular value decomposition is available, the referenced result proves the computable formula \[ \begin{align} \|\bA\|_2=\sqrt{\lambda_{\max}(\bA^T\bA)}=\sigma_{\max}(\bA). \end{align} \]

NoteTheorem: Orthogonal Transformations Have Unit Euclidean Norm

If \(\bQ^T\bQ=\bI\), then \[ \begin{align} \|\bQ\bx\|_2=\|\bx\|_2 \qquad\text{and}\qquad \|\bQ\|_2=1. \end{align} \]

WarningExercise

Compute \(\|\bQ\bx\|_2^2\) using \(\bQ^T\bQ=\bI\). Then take the maximum over unit vectors. Does the argument require \(\bQ\) to be square?

3.2 Dual Norms

An inner product turns a vector \(\by\) into the linear measurement \(\bx\mapsto\by^T\bx\). The dual norm measures the largest value of this measurement on the unit ball.

NoteDefinition: Dual Norm

For a norm \(\|\cdot\|\) on \(\fR^n\), its dual norm is \[ \begin{align} \|\by\|_* =\max_{\|\bx\|=1}|\by^T\bx|. \end{align} \] Consequently, \[ \begin{align} |\by^T\bx|\leq\|\by\|_*\|\bx\|. \end{align} \]

NoteTheorem: Duals of the Standard Norms

The Euclidean norm is self-dual. The \(1\)- and infinity norms are dual to one another: \[ \begin{align} \|\by\|_{2,*}=\|\by\|_2, \qquad \|\by\|_{1,*}=\|\by\|_\infty, \qquad \|\by\|_{\infty,*}=\|\by\|_1. \end{align} \]

TipProof

For a dual norm, an upper estimate alone is insufficient. We must also find a unit vector attaining that estimate. If \(\by=\bzero\), every claimed norm is zero. Assume below that \(\by\neq\bzero\).

  1. For \(\|\bx\|_2=1\), Cauchy–Schwarz gives \(|\by^T\bx|\leq\|\by\|_2\). Choose \(\bx=\by/\|\by\|_2\). It is a unit vector, and \(\by^T\bx=\|\by\|_2\). Hence the maximum is exactly \(\|\by\|_2\).

  2. For \(\|\bx\|_1=1\), \[ \begin{align} |\by^T\bx|\leq\sum_i|y_i||x_i| \leq(\max_i|y_i|)\sum_i|x_i|=\|\by\|_\infty. \end{align} \] Choose an index \(j\) of largest \(|y_j|\) and set \(\bx=\operatorname{sign}(y_j)\be_j\). Its \(1\)-norm is one and \(\by^T\bx=|y_j|=\|\by\|_\infty\).

  3. For \(\|\bx\|_\infty=1\), \[ \begin{align} |\by^T\bx|\leq\sum_i|y_i||x_i|\leq\sum_i|y_i|=\|\by\|_1. \end{align} \] Set \(x_i=1\) if \(y_i\geq0\) and \(x_i=-1\) if \(y_i<0\). Then \(\|\bx\|_\infty=1\) and every product \(y_ix_i\) equals \(|y_i|\). Thus equality is attained.

Dual norms explain why the norm used for a residual determines the norm that appears in the corresponding linear functional. They also explain the row-sum and column-sum formulas above. The transpose interchanges inputs with linear measurements, giving the useful identity \[ \begin{align} \|\bA\|_1=\|\bA^T\|_\infty. \end{align} \]

3.3 The Frobenius Norm

Matrices themselves form a vector space. When a matrix is being treated as data rather than as an operator, the natural Euclidean measurement is entrywise.

NoteDefinition: Frobenius Inner Product and Norm

For matrices \(\bA,\bB\in\fR^{m\times n}\), the Frobenius inner product is \[ \begin{align} \langle\bA,\bB\rangle_F =\sum_{i=1}^m\sum_{j=1}^n a_{ij}b_{ij} =\operatorname{trace}(\bA^T\bB). \end{align} \] Its induced norm is \[ \begin{align} \|\bA\|_F =\left(\sum_{i=1}^m\sum_{j=1}^n a_{ij}^2\right)^{1/2}. \end{align} \]

WarningExercise

Frobenius geometry. Verify the inner-product axioms for \(\langle\bA,\bB\rangle_F\). Prove the matrix Cauchy–Schwarz inequality \(|\langle\bA,\bB\rangle_F|\leq\|\bA\|_F\|\bB\|_F\) by treating the entries as vectors.

TipRemark

(Two different questions) The Frobenius norm measures the collective size of the entries. The induced \(2\)-norm measures the largest amplification of a vector. Both are useful, but they answer different questions. Calling both a ``matrix norm’’ does not make them interchangeable.

NoteTheorem: Bounds Relating Frobenius and Operator Norms

For \(\bA\in\fR^{m\times n}\), \[ \begin{align} \|\bA\|_2\leq\|\bA\|_F\leq\sqrt n\,\|\bA\|_2. \end{align} \] For compatible matrices \(\bA\) and \(\bB\), \[ \begin{align} \|\bA\bB\|_F\leq\|\bA\|_2\|\bB\|_F. \end{align} \]

TipProof

Let \(\ba_i^T\) denote row \(i\) of \(\bA\). For \(\|\bx\|_2=1\), each output entry is \(\ba_i^T\bx\). Cauchy–Schwarz applies separately in each row: \[ \begin{align} \|\bA\bx\|_2^2 =\sum_{i=1}^m|\ba_i^T\bx|^2 \leq\sum_{i=1}^m\|\ba_i\|_2^2\|\bx\|_2^2 =\sum_{i,j}a_{ij}^2=\|\bA\|_F^2. \end{align} \] Taking the maximum over unit \(\bx\) and then square roots gives \(\|\bA\|_2\leq\|\bA\|_F\).

For the opposite comparison, use columns instead of rows. Column \(j\) is \(\bA\be_j\), and \(\|\be_j\|_2=1\). Consistency gives \(\|\bA\be_j\|_2\leq\|\bA\|_2\). Summing the squared estimates over all \(n\) columns yields \[ \begin{align} \|\bA\|_F^2=\sum_{j=1}^n\|\bA\be_j\|_2^2 \leq\sum_{j=1}^n\|\bA\|_2^2=n\|\bA\|_2^2. \end{align} \] The nonnegative square root gives the factor \(\sqrt n\).

Finally let \(\bB\in\fR^{n\times k}\) have columns \(\bb_1,...,\bb_k\). Column \(j\) of the product is \(\bA\bb_j\). Apply consistency to each such column before summing: \[ \begin{align} \|\bA\bB\|_F^2 &=\sum_{j=1}^k\|\bA\bb_j\|_2^2\\ &\leq\sum_{j=1}^k\|\bA\|_2^2\|\bb_j\|_2^2\\ &=\|\bA\|_2^2\|\bB\|_F^2. \end{align} \] Taking square roots proves the product estimate. The dimensions \(n\) and \(k\) enter only through the corresponding sums over columns.

3.4 Matrix Condition Numbers

An invertible matrix can stretch some directions and compress others. A solve with that matrix must undo both effects. The condition number measures the total distortion.

NoteDefinition: Condition Number

For a nonsingular square matrix \(\bA\) and an induced norm, \[ \begin{align} \kappa(\bA)=\|\bA\|\,\|\bA^{-1}\|. \end{align} \]

NoteTheorem: Two-Sided Stretching Bound

For every nonzero vector \(\bx\), \[ \begin{align} \frac{1}{\|\bA^{-1}\|} \leq \frac{\|\bA\bx\|}{\|\bx\|} \leq \|\bA\|. \end{align} \] The ratio between the largest possible upper stretch and the guaranteed lower stretch is \(\kappa(\bA)\).

TipProof

The assumption that \(\bA\) is nonsingular is needed for the lower estimate. Fix \(\bx\neq\bzero\).

  1. By the definition of the induced norm, the ratio for this particular input cannot exceed the largest possible ratio: \[ \begin{align} \frac{\|\bA\bx\|}{\|\bx\|}\leq \sup_{\bz\neq\bzero}\frac{\|\bA\bz\|}{\|\bz\|}=\|\bA\|. \end{align} \]

  2. Undo the action of \(\bA\) and apply consistency to its inverse: \[ \begin{align} \bx&=\bA^{-1}(\bA\bx),\\ \|\bx\|&\leq\|\bA^{-1}\|\|\bA\bx\|. \end{align} \] Both \(\|\bx\|\) and \(\|\bA^{-1}\|\) are positive. Dividing by their product gives \[ \begin{align} \frac1{\|\bA^{-1}\|}\leq\frac{\|\bA\bx\|}{\|\bx\|}. \end{align} \]

  3. The upper stretch is \(\|\bA\|\) and the lower stretch is \(1/\|\bA^{-1}\|\). Dividing the former by the latter gives \(\|\bA\|\|\bA^{-1}\|=\kappa(\bA)\).

WarningExercise

Conditioning as a thin ellipse. Let \(\bA=\operatorname{diag}(1,\varepsilon)\) with \(0<\varepsilon<1\). Describe the image of the Euclidean unit circle, compute \(\|\bA\|_2\), \(\|\bA^{-1}\|_2\), and \(\kappa_2(\bA)\) directly from the definition, and explain which component of a solution is sensitive to perturbations.

If \(\kappa(\bA)\) is near one, the matrix treats every direction comparably. If it is large, at least one direction is compressed relative to another. Recovering a component in a strongly compressed direction requires amplification by \(\bA^{-1}\). Consequently, ill-conditioned linear systems can turn small data errors into large solution errors. the referenced result makes this statement quantitative.

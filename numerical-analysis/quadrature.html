20  Numerical Quadrature

Numerical quadrature approximates the definite integral of a continuous function \(f : [a, b] \to \fR\) by a finite linear combination of sampled function values: \[ \begin{align} I(f) = \int_a^b f(x)\,dx \approx Q_n(f) = \sum_{i=0}^n w_i f(x_i). \end{align} \] The points \(x_i \in [a, b]\) are the quadrature nodes, and the scalar coefficients \(w_i \in \fR\) are the quadrature weights. The design of quadrature rules balances algebraic precision, computational cost, and numerical stability.

20.1 Degree of Exactness and Interpolatory Quadrature

The standard criterion for evaluating a quadrature rule is its algebraic precision, defined by the highest degree of polynomials it integrates without error.

NoteDefinition: Degree of Exactness (Algebraic Precision)

A quadrature rule \(Q_n\) has degree of exactness \(m\) if \[ \begin{align} Q_n(p) = \int_a^b p(x)\,dx \qquad \text{for all } p \in \mathcal{P}_m, \end{align} \] and there exists at least one polynomial \(q \in \mathcal{P}_{m+1}\) for which \(Q_n(q) \neq \int_a^b q(x)\,dx\).

NoteTheorem: Interpolatory Quadrature Rules

Let \(x_0, x_1, ..., x_n\) be \(n+1\) distinct nodes in \([a, b]\). The interpolatory quadrature rule approximates \(I(f)\) by integrating the polynomial interpolant \(P_n(x) = \sum_{i=0}^n f(x_i) L_i(x)\) in Lagrange form: \[ \begin{align} Q_n(f) = \int_a^b P_n(x)\,dx = \sum_{i=0}^n w_i f(x_i), \qquad w_i = \int_a^b L_i(x)\,dx. \end{align} \] Every interpolatory quadrature rule with \(n+1\) distinct nodes has degree of exactness at least \(n\).

TipProof

Let \(p \in \mathcal{P}_n\). By the uniqueness of polynomial interpolation (the referenced result), the interpolant of \(p\) is identical to \(p\) itself: \(P_n(x) \equiv p(x)\). Integrating this identity yields \[ \begin{align} \int_a^b p(x)\,dx = \int_a^b P_n(x)\,dx = \int_a^b \left( \sum_{i=0}^n p(x_i) L_i(x) \right) dx = \sum_{i=0}^n p(x_i) \int_a^b L_i(x)\,dx = \sum_{i=0}^n w_i p(x_i) = Q_n(p). \end{align} \] Therefore, \(Q_n\) integrates all polynomials of degree at most \(n\) exactly.

20.2 Newton–Cotes Formulas and Composite Rules

Newton–Cotes rules are interpolatory quadrature formulas built on equally spaced nodes. Because high-order single-panel Newton–Cotes rules suffer from negative weights and Runge’s phenomenon, practical computations use composite rules on small subintervals of uniform width \(h = (b - a)/N\).

NoteDefinition: Composite Trapezoidal and Simpson’s Rules

Dividing \([a, b]\) into \(N\) subintervals with uniform width \(h = (b - a)/N\) and grid points \(x_j = a + jh\):

  1. The Composite Trapezoidal Rule is \[ \begin{align} T_N(f) = h \left[ \frac{f(a) + f(b)}{2} + \sum_{j=1}^{N-1} f(x_j) \right]. \end{align} \]

  2. For an even number of panels \(N\), the Composite Simpson’s Rule is \[ \begin{align} S_N(f) = \frac{h}{3} \left[ f(x_0) + 4\sum_{\substack{j=1 \\ j \text{ odd}}}^{N-1} f(x_j) + 2\sum_{\substack{j=2 \\ j \text{ even}}}^{N-2} f(x_j) + f(x_N) \right]. \end{align} \]

NoteTheorem: Composite Error Formulas

Let \(f \in C^2[a, b]\) for the trapezoidal rule, and let \(f \in C^4[a, b]\) for Simpson’s rule.

  1. The composite trapezoidal error satisfies \[ \begin{align} I(f) - T_N(f) = -\frac{b - a}{12} h^2 f''(\xi_T), \qquad \xi_T \in (a, b). \end{align} \]

  2. The composite Simpson error satisfies \[ \begin{align} I(f) - S_N(f) = -\frac{b - a}{180} h^4 f^{(4)}(\xi_S), \qquad \xi_S \in (a, b). \end{align} \]

TipProof

For the trapezoidal rule on panel \([x_j, x_{j+1}]\), the Cauchy interpolation error formula (the referenced result) gives \[ \begin{align} f(x) - P_1(x) = \frac{f''(\xi_j(x))}{2}(x - x_j)(x - x_{j+1}). \end{align} \] Because \((x - x_j)(x - x_{j+1}) \leq 0\) on this panel, the Mean Value Theorem for Integrals implies there exists \(\mu_j \in (x_j, x_{j+1})\) such that \[ \begin{align} \int_{x_j}^{x_{j+1}} [f(x) - P_1(x)]\,dx = \frac{f''(\mu_j)}{2} \int_{x_j}^{x_{j+1}} (x - x_j)(x - x_{j+1})\,dx = -\frac{h^3}{12} f''(\mu_j). \end{align} \] Summing across all \(N\) panels and applying the Intermediate Value Theorem to the average \(\frac{1}{N}\sum_{j=0}^{N-1} f''(\mu_j) = f''(\xi_T)\) yields the trapezoidal error formula: \[ \begin{align} I(f) - T_N(f) = -\frac{h^3}{12} \sum_{j=0}^{N-1} f''(\mu_j) = -\frac{N h^3}{12} f''(\xi_T) = -\frac{b - a}{12} h^2 f''(\xi_T). \end{align} \] For Simpson’s rule, expand \(f(x_{2j+1} + t)\) about the midpoint \(c_j = x_{2j+1}\) through fourth order for \(t \in [-h, h]\): \[ \begin{align} f(c_j + t) = f(c_j) + t f'(c_j) + \frac{t^2}{2} f''(c_j) + \frac{t^3}{6} f'''(c_j) + \frac{t^4}{24} f^{(4)}(c_j) + O(t^5). \end{align} \] Integrating over \([-h, h]\), odd powers vanish by symmetry: \[ \begin{align} \int_{c_j - h}^{c_j + h} f(x)\,dx = \int_{-h}^h f(c_j + t)\,dt = 2h f(c_j) + \frac{h^3}{3} f''(c_j) + \frac{h^5}{60} f^{(4)}(c_j) + O(h^7). \end{align} \] The Simpson rule on this double-panel evaluates to \[ \begin{align} S_{\text{panel}} &= \frac{h}{3} \left[ f(c_j - h) + 4 f(c_j) + f(c_j + h) \right] \\ &= \frac{h}{3} \left[ 6 f(c_j) + h^2 f''(c_j) + \frac{h^4}{12} f^{(4)}(c_j) + O(h^6) \right] \\ &= 2h f(c_j) + \frac{h^3}{3} f''(c_j) + \frac{h^5}{36} f^{(4)}(c_j) + O(h^7). \end{align} \] Subtracting gives the single-panel error: \[ \begin{align} \int_{c_j - h}^{c_j + h} f(x)\,dx - S_{\text{panel}} = \left( \frac{1}{60} - \frac{1}{36} \right) h^5 f^{(4)}(\mu_j) = -\frac{h^5}{90} f^{(4)}(\mu_j). \end{align} \] Summing over all \(N/2\) double panels and applying the Intermediate Value Theorem gives \[ \begin{align} I(f) - S_N(f) = -\frac{h^5}{90} \sum_{j=0}^{N/2 - 1} f^{(4)}(\mu_j) = -\frac{N h^5}{180} f^{(4)}(\xi_S) = -\frac{b - a}{180} h^4 f^{(4)}(\xi_S). \end{align} \]

20.3 Peano Kernel Error Representation

The Peano kernel theorem provides a unified framework for representing the error of any quadrature rule with algebraic degree of exactness \(m\).

NoteTheorem: Peano Kernel Theorem

Let \(Q\) be a quadrature rule on \([a, b]\) with error functional \(E(f) = \int_a^b f(x)\,dx - Q(f)\). If \(E(p) = 0\) for all \(p \in \mathcal{P}_m\), then for every \(f \in C^{m+1}[a, b]\), \[ \begin{align} E(f) = \int_a^b f^{(m+1)}(t) K(t)\,dt, \end{align} \] where the Peano kernel \(K(t)\) is defined by applying the error functional to the truncated power function: \[ \begin{align} K(t) = \frac{1}{m!} E_x \left( (x - t)_+^m \right), \qquad (x - t)_+ = \max(0, x - t). \end{align} \] If \(K(t)\) does not change sign on \([a, b]\), then there exists \(\xi \in (a, b)\) such that \[ \begin{align} E(f) = \frac{f^{(m+1)}(\xi)}{(m+1)!} E(x^{m+1}). \end{align} \]

TipProof

By Taylor’s theorem with integral remainder expanded about \(a\): \[ \begin{align} f(x) = \sum_{k=0}^m \frac{f^{(k)}(a)}{k!} (x - a)^k + \frac{1}{m!} \int_a^x f^{(m+1)}(t) (x - t)^m\,dt. \end{align} \] Extending the upper integration limit using the truncated power notation \((x - t)_+^m\) allows writing the remainder as \(\frac{1}{m!} \int_a^b f^{(m+1)}(t) (x - t)_+^m\,dt\). Applying the linear functional \(E\) to both sides, the polynomial terms vanish because \(E(p) = 0\) for all \(p \in \mathcal{P}_m\). Exchanging the order of integration and the functional gives \[ \begin{align} E(f) = E_x \left( \frac{1}{m!} \int_a^b f^{(m+1)}(t) (x - t)_+^m\,dt \right) = \int_a^b f^{(m+1)}(t) \left[ \frac{1}{m!} E_x\left( (x - t)_+^m \right) \right] dt = \int_a^b f^{(m+1)}(t) K(t)\,dt. \end{align} \] If \(K(t)\) is of constant sign, the Mean Value Theorem for Integrals implies \(E(f) = f^{(m+1)}(\xi) \int_a^b K(t)\,dt\). Testing the identity with \(f(x) = x^{m+1}\), we have \(f^{(m+1)}(x) = (m+1)!\), which yields \(E(x^{m+1}) = (m+1)! \int_a^b K(t)\,dt\). Substituting this integral proves the claim.

20.4 Gauss–Legendre Quadrature

Newton–Cotes rules fix equispaced nodes and optimize only the weights. Gaussian quadrature optimizes both the nodes \(x_1, ..., x_p\) and the weights \(w_1, ..., w_p\), providing \(2p\) degrees of freedom to maximize the degree of exactness.

NoteLemma: Roots of Orthogonal Polynomials

Let \(P_p(x)\) be the degree-\(p\) Legendre polynomial orthogonal on \([-1, 1]\) with respect to weight \(w(x) \equiv 1\): \[ \begin{align} \int_{-1}^1 P_p(x) q(x)\,dx = 0 \qquad \text{for all } q \in \mathcal{P}_{p-1}. \end{align} \] Then \(P_p(x)\) has exactly \(p\) distinct, real roots, and all roots lie in the open interval \((-1, 1)\).

TipProof

Let \(x_1, ..., x_k\) denote the points in \((-1, 1)\) where \(P_p(x)\) changes sign. Because \(P_p\) is continuous and orthogonal to the constant polynomial \(q(x) = 1\), we have \(\int_{-1}^1 P_p(x)\,dx = 0\), so \(P_p\) must change sign at least once in \((-1, 1)\), meaning \(k \geq 1\). Suppose for contradiction that \(k < p\). Construct the polynomial \(q(x) = \prod_{j=1}^k (x - x_j) \in \mathcal{P}_k\). By construction, \(P_p(x)\) and \(q(x)\) change sign at identical points in \((-1, 1)\), so their product \(P_p(x) q(x)\) has constant sign on \([-1, 1]\) and is not identically zero. Consequently, \[ \begin{align} \int_{-1}^1 P_p(x) q(x)\,dx \neq 0. \end{align} \] However, because \(\deg(q) = k < p\), orthogonality requires \(\int_{-1}^1 P_p(x) q(x)\,dx = 0\), producing a contradiction. Therefore, \(k = p\), proving that \(P_p\) has \(p\) distinct real roots in \((-1, 1)\).

NoteTheorem: Fundamental Theorem of Gaussian Quadrature

Let \(x_1, ..., x_p\) be the roots of the degree-\(p\) Legendre polynomial \(P_p(x)\) on \([-1, 1]\), and let \(w_i = \int_{-1}^1 L_i(x)\,dx\). The \(p\)-point Gauss–Legendre quadrature rule \[ \begin{align} \int_{-1}^1 f(x)\,dx \approx \sum_{i=1}^p w_i f(x_i) \end{align} \] has degree of exactness \(2p - 1\). No \(p\)-point quadrature rule can achieve a degree of exactness higher than \(2p - 1\). Furthermore, all weights are strictly positive: \(w_i > 0\) for all \(i = 1, ..., p\).

TipProof

Let \(f \in \mathcal{P}_{2p-1}\). Polynomial long division of \(f(x)\) by \(P_p(x)\) yields \[ \begin{align} f(x) = q(x) P_p(x) + r(x), \qquad \deg(q) \leq p - 1, \quad \deg(r) \leq p - 1. \end{align} \] Integrating both sides over \([-1, 1]\): \[ \begin{align} \int_{-1}^1 f(x)\,dx = \int_{-1}^1 q(x) P_p(x)\,dx + \int_{-1}^1 r(x)\,dx. \end{align} \] Because \(\deg(q) \leq p - 1\), orthogonality of \(P_p\) against \(\mathcal{P}_{p-1}\) implies \(\int_{-1}^1 q(x) P_p(x)\,dx = 0\), giving \[ \begin{align} \int_{-1}^1 f(x)\,dx = \int_{-1}^1 r(x)\,dx. \end{align} \] Applying the \(p\)-point quadrature sum at the Legendre roots \(\{x_i\}_{i=1}^p\) where \(P_p(x_i) = 0\): \[ \begin{align} \sum_{i=1}^p w_i f(x_i) &= \sum_{i=1}^p w_i \left[ q(x_i) P_p(x_i) + r(x_i) \right] \\ &= \sum_{i=1}^p w_i \left[ 0 + r(x_i) \right] = \sum_{i=1}^p w_i r(x_i). \end{align} \] Because \(\deg(r) \leq p - 1\), interpolatory quadrature on \(p\) distinct nodes integrates \(r(x)\) exactly by the referenced result: \[ \begin{align} \sum_{i=1}^p w_i r(x_i) = \int_{-1}^1 r(x)\,dx = \int_{-1}^1 f(x)\,dx. \end{align} \] Thus \(\sum_{i=1}^p w_i f(x_i) = \int_{-1}^1 f(x)\,dx\) for all \(f \in \mathcal{P}_{2p-1}\). To prove that \(2p - 1\) is the maximal degree, define the nodal polynomial \[ \begin{align} g(x) = \prod_{i=1}^p (x - x_i)^2 \in \mathcal{P}_{2p}. \end{align} \] Because \(g(x) \geq 0\) and vanishes only at isolated points, its integral is strictly positive: \[ \begin{align} \int_{-1}^1 g(x)\,dx > 0. \end{align} \] However, evaluating the quadrature sum yields \[ \begin{align} \sum_{i=1}^p w_i g(x_i) = \sum_{i=1}^p w_i \cdot 0 = 0 \neq \int_{-1}^1 g(x)\,dx. \end{align} \] Therefore no \(p\)-point quadrature rule can integrate all degree-\(2p\) polynomials. For weight positivity, let \(L_i \in \mathcal{P}_{p-1}\) be the \(i\)-th Lagrange basis polynomial. The square satisfies \(\deg(L_i^2) = 2p - 2 \leq 2p - 1\). The rule integrates \(L_i^2\) exactly: \[ \begin{align} 0 < \int_{-1}^1 L_i^2(x)\,dx = \sum_{j=1}^p w_j L_i^2(x_j) = \sum_{j=1}^p w_j \delta_{ij} = w_i. \end{align} \] Every weight \(w_i\) is strictly positive.

20.5 Richardson Extrapolation and Romberg Integration

When the error of a numerical method admits an asymptotic expansion in powers of \(h\), Richardson extrapolation algebraically cancels the leading error terms.

NoteTheorem: Euler–Maclaurin Summation and Romberg Integration

Let \(f \in C^{2m+2}[a, b]\). The composite trapezoidal rule satisfies the asymptotic expansion \[ \begin{align} T(h) = I(f) + c_2 h^2 + c_4 h^4 + c_6 h^6 + ... + c_{2m} h^{2m} + O(h^{2m+2}), \end{align} \] where \(c_{2k} = \frac{B_{2k}}{(2k)!}[f^{(2k-1)}(b) - f^{(2k-1)}(a)]\) depend on the Bernoulli numbers \(B_{2k}\). Romberg integration systematically eliminates powers of \(h^2\) via the tableau recurrence \[ \begin{align} R(k, 0) = T(h_k), \qquad R(k, j) = \frac{4^j R(k, j-1) - R(k-1, j-1)}{4^j - 1} \quad (1 \leq j \leq k), \end{align} \] where \(h_k = (b - a)/2^k\). Column \(j\) achieves order \(O(h^{2j+2})\).

TipProof

At column 1, \(R(k, 0) = I(f) + c_2 h_k^2 + O(h_k^4)\) and \(R(k-1, 0) = I(f) + c_2 (2h_k)^2 + O(h_k^4) = I(f) + 4 c_2 h_k^2 + O(h_k^4)\). Forming the linear combination \[ \begin{align} \frac{4 R(k, 0) - R(k-1, 0)}{3} = \frac{4(I(f) + c_2 h_k^2) - (I(f) + 4 c_2 h_k^2)}{3} + O(h_k^4) = I(f) + O(h_k^4) \end{align} \] cancels the \(h^2\) error term. Induction on \(j\) shows that combining step sizes differing by a factor of 2 cancels the leading \(h^{2j}\) error term with weights \(\frac{4^j}{4^j - 1}\) and \(-\frac{1}{4^j - 1}\).

20.6 Periodic Functions and Spectral Convergence

NoteTheorem: Spectral Accuracy of the Trapezoidal Rule on Periodic Domains

Let \(f\) be a smooth, \(2\pi\)-periodic function on \(\fR\). All endpoint derivatives in the Euler–Maclaurin expansion cancel identically: \[ \begin{align} f^{(2k-1)}(2\pi) - f^{(2k-1)}(0) = 0 \qquad \text{for all } k \geq 1. \end{align} \] Consequently, all algebraic error coefficients \(c_2, c_4, c_6, ...\) vanish. If \(f\) is analytic in a strip \(\{z \in \fC : |\operatorname{Im}(z)| < d\}\), the composite trapezoidal rule converges exponentially fast: \[ \begin{align} |I(f) - T_N(f)| \leq C e^{-d N}. \end{align} \] On smooth periodic domains, the composite trapezoidal rule achieves spectral accuracy.

TipProof

Because \(f\) is periodic and smooth, \(f^{(m)}(2\pi) = f^{(m)}(0)\) for all \(m \geq 0\). Every term \(c_{2k}\) in the Euler–Maclaurin formula is proportional to \(f^{(2k-1)}(2\pi) - f^{(2k-1)}(0) = 0\), so the error decays faster than any power of \(h = 2\pi / N\). To quantify the exponential rate, expand \(f(x)\) in its Fourier series: \[ \begin{align} f(x) = \sum_{k=-\infty}^\infty \hat{f}_k e^{ikx}, \qquad \hat{f}_k = \frac{1}{2\pi} \int_0^{2\pi} f(x) e^{-ikx}\,dx. \end{align} \] The exact integral is \(I(f) = \int_0^{2\pi} f(x)\,dx = 2\pi \hat{f}_0\). The composite trapezoidal rule with \(h = 2\pi / N\) and nodes \(x_j = 2\pi j / N\) for \(j = 0, ..., N - 1\) gives \[ \begin{align} T_N(f) = \frac{2\pi}{N} \sum_{j=0}^{N-1} f(x_j) &= \frac{2\pi}{N} \sum_{j=0}^{N-1} \sum_{k=-\infty}^\infty \hat{f}_k e^{2\pi i j k / N} \\ &= 2\pi \sum_{k=-\infty}^\infty \hat{f}_k \left( \frac{1}{N} \sum_{j=0}^{N-1} e^{2\pi i j k / N} \right). \end{align} \] The inner sum satisfies discrete orthogonality: \[ \begin{align} \frac{1}{N} \sum_{j=0}^{N-1} e^{2\pi i j k / N} = \begin{cases} 1, & k = mN \text{ for some } m \in \fZ, \\ 0, & k \not\equiv 0 \pmod N. \end{cases} \end{align} \] Substituting this indicator isolates the aliased modes: \[ \begin{align} T_N(f) = 2\pi \sum_{m=-\infty}^\infty \hat{f}_{mN} = 2\pi \hat{f}_0 + 2\pi \sum_{m \neq 0} \hat{f}_{mN}. \end{align} \] The quadrature error is therefore the tail sum: \[ \begin{align} I(f) - T_N(f) = -2\pi \sum_{m \neq 0} \hat{f}_{mN}. \end{align} \] Because \(f\) is analytic and bounded by \(M_0\) in the strip \(|\operatorname{Im}(z)| < d\), shifting the integration path in the definition of \(\hat{f}_k\) gives the geometric decay \(|\hat{f}_k| \leq M e^{-d|k|}\). Applying this bound: \[ \begin{align} |I(f) - T_N(f)| \leq 2\pi M \sum_{m \neq 0} e^{-d|m|N} = 4\pi M \sum_{m=1}^\infty (e^{-dN})^m = 4\pi M \frac{e^{-dN}}{1 - e^{-dN}} = O(e^{-dN}). \end{align} \]

20.7 Exercises

WarningExercise

  1. Derive. Method of undetermined coefficients. Find the nodes and weights for a symmetric 3-point rule on \([-1, 1]\) of the form \(\int_{-1}^1 f(x)\,dx \approx w_0 f(-\alpha) + w_1 f(0) + w_2 f(\alpha)\).

    1. For fixed \(\alpha = 1\), enforce exactness for \(f(x) = 1, x, x^2\) to derive the weights of Simpson’s rule: \(w_0 = 1/3, w_1 = 4/3, w_2 = 1/3\).

    2. Let \(\alpha\) be a free parameter. Enforce exactness for \(f(x) = 1, x^2, x^4\) to derive the Gauss–Legendre parameter \(\alpha = 1/\sqrt{3}\) and weights \(w_0 = w_2 = 1, w_1 = 0\).

    3. Compare the degree of exactness of both rules.

  2. Compute. Romberg tableau construction. Approximate the integral \(I = \int_0^1 e^{-x^2}\,dx\).

    1. Compute \(T(h)\) for \(h = 1, 1/2, 1/4\) using the composite trapezoidal rule.

    2. Construct the first three rows of the Romberg tableau to evaluate \(R(1, 1), R(2, 1)\), and \(R(2, 2)\).

    3. Confirm that \(R(1, 1)\) matches composite Simpson’s rule with \(N = 2\).

  3. Compute. Change of interval and Gaussian quadrature. Let \(\int_a^b f(t)\,dt\) be an integral on an arbitrary interval \([a, b]\).

    1. Derive the affine substitution \(t(x) = \frac{b - a}{2}x + \frac{a + b}{2}\) mapping \(x \in [-1, 1]\) to \(t \in [a, b]\).

    2. Transform the 2-point Gauss–Legendre rule to \([0, 3]\) and approximate \(\int_0^3 \sqrt{1 + t^3}\,dt\).

    3. Compare the result with Simpson’s rule using the same number of function evaluations.

  4. Derive. Peano kernel of the trapezoidal rule. Consider the single-panel trapezoidal rule on \([0, h]\) with error functional \(E(f) = \int_0^h f(x)\,dx - \frac{h}{2}[f(0) + f(h)]\).

    1. Show that \(E(1) = 0\) and \(E(x) = 0\), so \(m = 1\).

    2. Evaluate the Peano kernel \(K(t) = E_x((x - t)_+) = \int_0^h (x - t)_+\,dx - \frac{h}{2}[(0 - t)_+ + (h - t)_+]\).

    3. Show that \(K(t) = \frac{1}{2}t(t - h) \leq 0\) for all \(t \in [0, h]\).

    4. Apply the referenced result to compute \(\int_0^h K(t)\,dt = -\frac{h^3}{12}\) and recover the exact error term \(-\frac{h^3}{12} f''(\xi)\).

  5. Compute. Spectral accuracy on periodic integrals. Consider the integral \(I = \int_0^{2\pi} \frac{dx}{2 + \cos x} = \frac{2\pi}{\sqrt{3}}\).

    1. Identify the complex poles of \(f(z) = \frac{1}{2 + \cos z}\) by solving \(\cos z = -2\).

    2. Determine the half-width \(d\) of the strip of analyticity around the real axis.

    3. Evaluate \(T_N(f)\) for \(N = 4, 8, 16\). Confirm that \(|I - T_N(f)|\) decays as \(e^{-d N}\).

33  Markov Chains, Continuous Generators, and the CME

A finite random system has a probability of occupying each possible state. A Markov model specifies how these probabilities change using only the current state. We first use a matrix of transition probabilities for a discrete step, then a matrix of transition rates for continuous time.

The matrix conventions matter: throughout this section, probabilities are columns, so column \(j\) describes transitions out of state \(j\). We derive conservation and positivity, then assemble reaction models and examine the error introduced by retaining only a finite set of states.

33.1 Discrete-Time Markov Chains

NoteDefinition: Probability Vector

A vector \(\bx\in\fR^n\) is a probability vector if \[ \begin{align} x_i\geq 0,\qquad \sum_{i=1}^n x_i=1. \end{align} \] The entry \(x_i\) represents the probability of occupying state \(i\).

NoteDefinition: Column-Stochastic Matrix

A matrix \(\bP \in \fR^{n \times n}\) is column-stochastic if:

  1. \(P_{ij} \geq 0\) for all \(i,j\).

  2. \(\sum_{i=1}^n P_{ij} = 1\) for each column \(j\).

NoteExample

For two states, take \(\bP=\begin{pmatrix}0.8&0.1\\0.2&0.9\end{pmatrix}\). Starting in state one gives distribution \((0.8,0.2)^T\) after one step. Starting from probabilities \((0.6,0.4)^T\) gives a mixture of the two columns, namely \((0.52,0.48)^T\).

WarningExercise

Compute the second step for each initial distribution. Prove that multiplying any probability vector by a column-stochastic matrix produces another probability vector. Identify separately where you use nonnegative entries and where you use the column sums.

TipRemark

(Column convention) Column \(j\) of \(\bP\) contains the transition probabilities from state \(j\) to all destination states \(i\). The update rule for a probability distribution is \(\bx^{(k+1)} = \bP \bx^{(k)}\).

NoteTheorem: Spectrum of a Stochastic Matrix

If \(\bP\) is column-stochastic, then \(\lambda=1\) is an eigenvalue, and every eigenvalue satisfies \(|\lambda|\leq 1\).

TipProof

The column-sum condition can be written \(\mathbf1^T\bP=\mathbf1^T\). Taking transposes gives \(\bP^T\mathbf1=\mathbf1\), so one is an eigenvalue of \(\bP^T\). The characteristic polynomials of a matrix and its transpose agree, because \[ \begin{align} \det(\bP^T-z\bI)=\det((\bP-z\bI)^T)=\det(\bP-z\bI). \end{align} \] Hence one is also an eigenvalue of \(\bP\). The constant vector need not be its right eigenvector under the column convention.

To bound any eigenvalue, use an eigenvector \(\bv\neq\bzero\) of \(\bP^T\) with eigenvalue \(\lambda\). Choose \(j\) where \(|v_j|=\max_i|v_i|>0\). Its scalar eigenvalue equation is \[ \begin{align} \lambda v_j=\sum_i P_{ij}v_i. \end{align} \] Since the entries are nonnegative, \[ \begin{align} |\lambda||v_j| &\leq\sum_iP_{ij}|v_i|\\ &\leq\sum_iP_{ij}|v_j| =|v_j|\sum_iP_{ij}=|v_j|. \end{align} \] Divide by the positive number \(|v_j|\) to get \(|\lambda|\leq1\). The argument also covers complex eigenvectors because it uses absolute values. Equality of characteristic polynomials transfers this bound to every eigenvalue of \(\bP\).

NoteDefinition: Stationary Distribution

A probability vector \(\boldsymbol{\pi}\) is stationary if \(\bP \boldsymbol{\pi} = \boldsymbol{\pi}\). It is a right eigenvector of \(\bP\) associated with \(\lambda=1\), normalized so that \(\mathbf{1}^T\boldsymbol{\pi}=1\).

WarningExercise

The matrix \(\begin{pmatrix}0&1\\1&0\end{pmatrix}\) moves deterministically between two states. Find a stationary distribution, then start from \(\be_1\) and show that the distributions do not converge. A stationary distribution can exist without attracting every initial distribution. Which hypothesis of the following theorem rules out this example?

NoteTheorem: Perron–Frobenius for Markov Chains

If \(\bP\) is irreducible (every state can be reached from any other state in finitely many steps) and primitive (aperiodic, so \(\bP^k > 0\) elementwise for some \(k \geq 1\)), then:

  1. \(\lambda_1 = 1\) is an algebraically and geometrically simple eigenvalue.

  2. \(|\lambda_i| < 1\) for all other eigenvalues \(\lambda_i \neq 1\).

  3. The stationary distribution \(\boldsymbol{\pi}\) is strictly positive in every entry.

  4. For any initial probability vector \(\bx^{(0)}\), \(\lim_{k\to\infty} \bP^k \bx^{(0)} = \boldsymbol{\pi}\).

NoteDefinition: Spectral Gap and Mixing Time

For a primitive chain with eigenvalues ordered as \(1 = \lambda_1 > |\lambda_2| \geq ... \geq |\lambda_n|\), the spectral gap is \[ \begin{align} \delta = 1 - |\lambda_2|. \end{align} \] For a diagonalizable matrix, the error \(\|\bx^{(k)} - \boldsymbol{\pi}\|_2\) decays asymptotically as \(\mathcal{O}(|\lambda_2|^k)\). The number of steps \(k_\varepsilon\) required to reach error tolerance \(\varepsilon\) satisfies \[ \begin{align} k_\varepsilon \approx \frac{\log(1/\varepsilon)}{\delta}. \end{align} \]

WarningExercise

(Discrete spectrum and mixing) Under the column-stochastic convention, let \(\bP=\begin{pmatrix}0.8&0.1\\0.2&0.9\end{pmatrix}\). Find its stationary distribution \(\boldsymbol{\pi}\), its second eigenvalue, and the spectral gap \(\delta\). Starting from \(\bx^{(0)}=\be_1\), derive the exact formula for \(\|\bP^k\bx^{(0)}-\boldsymbol{\pi}\|_2\). Compare the first \(k\) for which this error is at most \(10^{-3}\) with the estimate \(\log(10^3)/\delta\), and explain why the latter is only an asymptotic rule.

NoteDefinition: Detailed Balance (Reversibility)

A Markov chain satisfies detailed balance with respect to \(\boldsymbol{\pi}\) if \[ \begin{align} P_{ij} \pi_j = P_{ji} \pi_i \qquad \text{for all } i, j. \end{align} \] A chain satisfying detailed balance is reversible.

NoteTheorem: Real Spectrum of Reversible Chains

Let \(\bP\) satisfy detailed balance with stationary distribution \(\boldsymbol{\pi} > 0\). Define \(\bD_{\boldsymbol{\pi}} = \operatorname{diag}(\boldsymbol{\pi})\). Then the matrix \[ \begin{align} \bS = \bD_{\boldsymbol{\pi}}^{-1/2} \bP \bD_{\boldsymbol{\pi}}^{1/2} \end{align} \] is symmetric. Consequently, all eigenvalues of \(\bP\) are real, and \(\bP\) has an orthogonal basis of eigenvectors in the inner product weighted by \(\bD_{\boldsymbol{\pi}}^{-1}\).

TipProof

Let \(\bD_{\boldsymbol\pi}\) have the positive stationary probabilities on its diagonal. Positivity makes its square root and inverse square root well defined. Entry \((i,j)\) of the transformed matrix is \[ \begin{align} S_{ij}=\pi_i^{-1/2}P_{ij}\pi_j^{1/2} =\frac{P_{ij}\pi_j}{\sqrt{\pi_i\pi_j}}. \end{align} \] Detailed balance changes the numerator to \(P_{ji}\pi_i\), giving \[ \begin{align} S_{ij}=\frac{P_{ji}\pi_i}{\sqrt{\pi_i\pi_j}} =\pi_j^{-1/2}P_{ji}\pi_i^{1/2}=S_{ji}. \end{align} \] Thus \(\bS\) is real symmetric and has a real orthonormal eigenbasis \(\bq_i\) with real eigenvalues \(\lambda_i\).

Undo the similarity. The vectors \(\bv_i=\bD_{\boldsymbol\pi}^{1/2}\bq_i\) satisfy \[ \begin{align} \bP\bv_i =\bD_{\boldsymbol\pi}^{1/2}\bS\bq_i =\lambda_i\bv_i. \end{align} \] The invertible change of coordinates preserves their independence, so they form a basis. In the claimed weighted inner product their pairings are \[ \begin{align} \bv_i^T\bD_{\boldsymbol\pi}^{-1}\bv_j =\bq_i^T\bD_{\boldsymbol\pi}^{1/2} \bD_{\boldsymbol\pi}^{-1}\bD_{\boldsymbol\pi}^{1/2}\bq_j =\bq_i^T\bq_j=\delta_{ij}. \end{align} \] This proves the weighted orthonormality assertion in addition to reality of the spectrum.

33.2 Continuous-Time Markov Chains and the CME

A rate differs from a probability. If the transition rate from \(j\) to \(i\) is \(A_{ij}\), then over a small time \(\Delta t\) the corresponding transition probability is \(A_{ij}\Delta t+o(\Delta t)\). The probability of remaining in \(j\) is one minus the total exit rate times \(\Delta t\), to first order. Thus the transition matrix has expansion \(\bI+\Delta t\bA+o(\Delta t)\), which explains the signs and column sums of a generator.

WarningExercise

For two states with rates \(1\to2\) equal to \(a>0\) and \(2\to1\) equal to \(b>0\), write the generator and derive both equations for \(p_1'\) and \(p_2'\). Show that \(p_1+p_2\) remains constant and find the stationary probabilities. Check the units of each matrix entry.

NoteDefinition: Continuous-Time Infinitesimal Generator

A continuous-time Markov jump process on a discrete state space evolves according to \[ \begin{align} \frac{d}{dt}\bp(t) = \bA \bp(t), \end{align} \] where \(\bp(t)\) is the probability distribution vector and \(\bA\) is an infinitesimal generator matrix satisfying:

  1. \(A_{ij} \geq 0\) for all \(i \neq j\) (transition rates between distinct states are nonnegative).

  2. \(\sum_{i} A_{ij} = 0\) for every column \(j\) (column sums vanish).

  3. \(A_{jj} = -\sum_{i \neq j} A_{ij} \leq 0\) (diagonal entries equal the negative total exit rate from state \(j\)).

WarningExercise

Choose \(\nu\geq\max_j(-A_{jj})\) with \(\nu>0\) and set \(\bP=\bI+\bA/\nu\). Prove that \(\bP\) is column-stochastic and that \[ \begin{align} e^{t\bA}=e^{-\nu t}\sum_{k=0}^{\infty}\frac{(\nu t)^k}{k!}\bP^k. \end{align} \] Deduce positivity, conservation of total mass, and \(\|e^{t\bA}\|_1=1\) for \(t\geq0\). Repeat the argument for a finite subgenerator whose column sums are nonpositive and prove that its exponential is substochastic. This construction is called uniformization.

A reaction model applies the same balance to molecule counts. Each term adds probability arriving from one neighboring count and subtracts probability leaving the current count. We take the propensity of an infeasible reaction to be zero, and terms involving states outside the nonnegative count space to be zero. For an infinite state space, conservation requires a nonexplosive process: only finitely many jumps occur in a finite time almost surely. The infinite-state statements below assume a well-defined conservative process and the summability needed for the displayed equations.

NoteDefinition: Chemical Master Equation (CME)

Consider a chemically reacting system with \(S\) molecular species and \(R\) reaction channels. The discrete state \(\bx \in \mathbb{N}_0^S\) records the copy number of each species. Each reaction channel \(k \in \{1,...,R\}\) is characterized by a stoichiometric change vector \(\bnu_k \in \mathbb{Z}^S\) and a propensity function \(\alpha_k(\bx; \bc) \geq 0\) parameterized by rate constants \(\bc\).

The Chemical Master Equation governs the probability \(p(\bx, t)\) of occupying state \(\bx\) at time \(t\): \[ \begin{align} \frac{\partial p(\bx, t)}{\partial t} = \sum_{k=1}^R \Big[ \alpha_k(\bx - \bnu_k; \bc)\, p(\bx - \bnu_k, t) - \alpha_k(\bx; \bc)\, p(\bx, t) \Big]. \end{align} \] Enumerating the reachable states yields the linear system of ordinary differential equations \[ \begin{align} \dot{\bp}(t) = \bA(\bc) \bp(t), \qquad \bp(0) = \bp_0, \end{align} \] whose exact formal solution is the matrix exponential action \(\bp(t) = \exp(t\bA(\bc)) \bp_0\).

WarningExercise

For births at constant rate \(\lambda\) and deaths at rate \(\mu x\), write the equation for \(p_x'(t)\). Treat \(x=0\) separately. Identify which terms represent arrivals and departures, and explain why a death term from state zero must vanish. Write the first three columns of the infinite generator.

33.3 Generator Assembly and Stochastic Simulation

Two computations start from the list of reactions. The first builds the generator \(\bA(\bc)\) on a finite set of states and evolves the whole distribution. The second samples individual trajectories of the jump process and never enumerates the state space. The generator is needed for the finite state projection below. Sampled trajectories provide the data for the Koopman estimators of the referenced section, and their histograms give an independent check on computed distributions.

NoteDefinition: Generator Assembly by Forward Enumeration

Let \(\mathcal S\) be a finite set of \(n\) states, stored in a hash table that maps each state \(\bx\) to its index \(\iota(\bx)\in\{1,...,n\}\). For each \(\bx\in\mathcal S\) and each reaction \(k\) with \(\alpha_k(\bx;\bc)>0\):

  1. Compute the destination \(\by=\bx+\bnu_k\).

  2. If \(\by\in\mathcal S\), append the triplet \(\big(\iota(\by),\iota(\bx),\alpha_k(\bx;\bc)\big)\).

Finally, append the diagonal triplet \(\big(\iota(\bx),\iota(\bx),-\sum_k\alpha_k(\bx;\bc)\big)\) for each \(\bx\), and convert the triplets to CSR format by the referenced result.

The diagonal entry contains the total exit rate, including the rates of reactions whose destination lies outside \(\mathcal S\). Column \(\iota(\bx)\) therefore sums to minus the rate at which probability leaves \(\mathcal S\) from \(\bx\), which is the leakage measured by the finite state projection bound. Assembly visits each pair of a state and a reaction once and performs one expected constant-time hash lookup for each, so it costs \(O(nR)\) operations and produces at most \(n(R+1)\) nonzero entries. Searching all pairs of states for possible transitions would cost \(O(n^2)\) instead.

NoteDefinition: Stochastic Simulation Algorithm

Let the process be in state \(\bx\) at time \(t\). Gillespie’s direct method advances it as follows (Gillespie 1977).

  1. Compute the propensities \(\alpha_k(\bx;\bc)\) and their sum \(a_0(\bx)=\sum_{k=1}^R\alpha_k(\bx;\bc)\). If \(a_0(\bx)=0\), stop.

  2. Draw independent \(u_1,u_2\) uniformly from \((0,1)\).

  3. Set \(\tau=-\ln(u_1)/a_0(\bx)\), and choose the smallest \(k\) with \(\sum_{l=1}^k\alpha_l(\bx;\bc)\geq u_2\,a_0(\bx)\).

  4. Replace \(t\) by \(t+\tau\) and \(\bx\) by \(\bx+\bnu_k\).

NoteTheorem: Exactness of the Stochastic Simulation Algorithm

Assume \(a_0(\bx)>0\), with zero-rate channels unable to fire. Suppose that from state \(\bx\) each positive-rate reaction \(k\) fires after an independent exponential waiting time with rate \(\alpha_k(\bx;\bc)\), and that the first reaction to fire determines the next state. Then the time to the next reaction is exponential with rate \(a_0(\bx)\), the next reaction is \(k\) with probability \(\alpha_k(\bx;\bc)/a_0(\bx)\), and these two events are independent. The waiting time and reaction index produced by the referenced result have exactly this joint distribution.

TipProof

Fix the current state and abbreviate its positive reaction rates by \(\alpha_k\), with \(a_0=\sum_k\alpha_k>0\). A rate-zero channel never fires and may be omitted. Let \(T_k\) be the independent exponential waiting time of channel \(k\), let \(T=\min_kT_k\), and let \(K\) be the first channel to fire. Ties have probability zero because these distributions are continuous.

For channel \(k\) to fire first at time \(s\), its waiting-time density contributes \(\alpha_ke^{-\alpha_ks}\), and every other waiting time must exceed \(s\). Independence multiplies their survival probabilities. Thus the joint density in time is \[ \begin{align} \Pr(K=k,\ T\in ds)/ds =\alpha_ke^{-\alpha_ks}\prod_{l\neq k}e^{-\alpha_ls} =\alpha_ke^{-a_0s}. \end{align} \] Integrate for \(s>\tau\): \[ \begin{align} \Pr(K=k,T>\tau) =\int_\tau^\infty\alpha_ke^{-a_0s}\,ds =\frac{\alpha_k}{a_0}e^{-a_0\tau}. \end{align} \] Setting \(\tau=0\) gives \(\Pr(K=k)=\alpha_k/a_0\). Summing over \(k\) gives \(\Pr(T>\tau)=e^{-a_0\tau}\). The joint expression is the product of these marginals, proving independence.

The algorithm reproduces both marginals. For \(u_1\) uniform on \((0,1)\), \[ \begin{align} \Pr(-\ln u_1/a_0>\tau)=\Pr(u_1<e^{-a_0\tau})=e^{-a_0\tau}. \end{align} \] The interval assigned to channel \(k\) by the cumulative sums has length \(\alpha_k\) in an interval of length \(a_0\). A uniform \(u_2a_0\) lands there with probability \(\alpha_k/a_0\). Independent uniforms preserve independence of the two selections. This proves exactness of this single jump, which can be repeated at each new state (Gillespie 1977).

Recomputing all propensities and selecting a reaction by linear search costs \(O(R)\) per event. A tree reduces the selection cost to \(O(\log R)\), but the total event cost also includes updating every propensity affected by the reaction. The number of steps up to time \(T\) is about \(\int_0^Ta_0(\bX(t))\,dt\), which is large when some reactions are fast. An expected value \(\mathbb{E}[f(\bX(T))]\) is estimated by averaging \(f\) over \(N\) independent trajectories. By the central limit theorem, the error of this average has standard deviation \(\sigma_f/\sqrt N\), where \(\sigma_f\) is the standard deviation of \(f(\bX(T))\). Each additional digit of accuracy therefore requires a hundred times more trajectories. The finite state projection below computes an approximation to the distribution instead. Its cost depends on the number of retained states and the accuracy required of both truncation and time propagation.

33.4 Finite State Projection (FSP)

TipRemark

(Truncating the state space) The CME generator \(\bA(\bc)\) is defined over an infinite or very large discrete state space \(\mathbb{N}_0^S\). A finite computation therefore requires truncation, aggregation, or another representation that avoids enumerating the full state space.

Truncating the state space removes paths after they leave the retained set. It should not redirect an outgoing transition back into that set. We therefore keep the original negative diagonal entries while dropping the off-diagonal entries for omitted destinations. The resulting loss of total probability measures the discrepancy caused by truncation. Renormalizing the remaining probabilities would conceal that loss.

NoteDefinition: Finite State Projection (FSP)

Let the discrete state space be partitioned into a finite retained index set \(J \subset \mathbb{N}_0^S\) with \(|J| = K\), and an infinite or omitted complement set \(J^c\). Permuting states so that \(J\) appears first partitions the full generator: \[ \begin{align} \bA = \begin{pmatrix} \bA_J & \bA_{J, J^c} \\ \bA_{J^c, J} & \bA_{J^c} \end{pmatrix}. \end{align} \] The Finite State Projection of Munsky and Khammash (Munsky and Khammash 2006) approximates the true marginal probability on \(J\) by solving the isolated subgenerator system \[ \begin{align} \dot{\bp}_J(t) = \bA_J \bp_J(t), \qquad \bp_J(0) = \bp_0|_J. \end{align} \] Here \(\bA_J\) has nonpositive diagonal entries and nonnegative off-diagonal entries, but its column sums are nonpositive because transitions into \(J^c\) act as probability leaks.

NoteTheorem: FSP 1-Norm Leakage Bound

Let \(\bp(t)\) be the exact probability distribution solving \(\dot{\bp} = \bA\bp\) with initial condition supported on \(J\), so that \(\mathbf{1}^T\bp(t) = 1\). Let \(\bp_J(t) = \exp(t\bA_J)\bp_0|_J\) be the FSP solution. Then:

  1. Pointwise underestimation: \(\bzero \leq \bp_J(t) \leq \bp|_J(t)\) for all \(t \geq 0\).

  2. The full-space error of the zero-padded FSP approximation equals the leaked mass: \[ \begin{align} \|\bp(t) - \widetilde{\bp}_J(t)\|_1 = 1 - \mathbf{1}^T\bp_J(t), \end{align} \] where \(\widetilde{\bp}_J(t)\) is \(\bp_J(t)\) padded with zeros on \(J^c\). The retained-state error satisfies \[ \begin{align} \|\bp|_J(t)-\bp_J(t)\|_1 =\mathbf{1}^T\bp|_J(t)-\mathbf{1}^T\bp_J(t) \leq 1-\mathbf{1}^T\bp_J(t). \end{align} \]

TipProof

The exact retained dynamics satisfy the non-autonomous subgenerator ODE \[ \begin{align} \frac{d}{dt}\bp|_J(t) = \bA_J\bp|_J(t) + \bA_{J,J^c}\bp|_{J^c}(t), \qquad \bp|_J(0) = \bp_0|_J. \end{align} \] The FSP approximation satisfies \(\frac{d}{dt}\bp_J(t) = \bA_J\bp_J(t)\) with the same initial condition \(\bp_J(0) = \bp_0|_J\). Subtracting the two equations gives the defect ODE for the difference \(\boldsymbol{\delta}_J(t) = \bp|_J(t) - \bp_J(t)\): \[ \begin{align} \frac{d}{dt}\boldsymbol{\delta}_J(t) = \bA_J \boldsymbol{\delta}_J(t) + \bA_{J,J^c}\bp|_{J^c}(t), \qquad \boldsymbol{\delta}_J(0) = \bzero. \end{align} \] The two retained trajectories have exactly the same initial data. Their difference therefore starts at zero. The only forcing in its equation is probability returning from omitted states, represented by the nonnegative coupling term.

By Duhamel’s formula (variation of constants): \[ \begin{align} \boldsymbol{\delta}_J(t) = \bp|_J(t) - \bp_J(t) = \int_0^t e^{(t-s)\bA_J}\bA_{J,J^c}\bp|_{J^c}(s)\,ds. \end{align} \] For the finite retained matrix, nonnegativity of its exponential follows from the uniformization construction already given: shift its diagonal by a sufficiently large positive multiple of the identity and expand the resulting nonnegative matrix in powers. Every term of that exponential series is nonnegative.

Because \(\bA_J\) has non-negative off-diagonal entries, it is a Metzler matrix, and its matrix exponential \(e^{\tau\bA_J}\) is entrywise non-negative for all \(\tau \geq 0\). Furthermore, the coupling matrix \(\bA_{J, J^c} \geq \bzero\) and exact probabilities \(\bp|_{J^c}(s) \geq \bzero\) are non-negative. Consequently, the integrand is entrywise non-negative, proving that \[ \begin{align} \bp|_J(t) - \bp_J(t) \geq \bzero \implies \bzero \leq \bp_J(t) \leq \bp|_J(t) \quad \text{for all } t \geq 0. \end{align} \]

Because \(\bp_J(t) \leq \bp|_J(t)\), the marginal 1-norm difference on \(J\) simplifies without absolute value signs: \[ \begin{align} \|\bp|_J(t) - \bp_J(t)\|_1 = \sum_{i \in J} \big( p_i(t) - [\bp_J(t)]_i \big) = \mathbf{1}^T\bp|_J(t) - \mathbf{1}^T\bp_J(t). \end{align} \] The total probability across the full space satisfies \(\mathbf{1}^T\bp|_J(t) + \mathbf{1}^T\bp|_{J^c}(t) = 1\). The omitted probability mass on \(J^c\) is exactly \(1 - \mathbf{1}^T\bp|_J(t)\). Adding the unmodeled mass on \(J^c\) gives \[ \begin{align} \|\bp(t) - \widetilde{\bp}_J(t)\|_1 &= \|\bp|_J(t) - \bp_J(t)\|_1 + \|\bp|_{J^c}(t)\|_1 \\ &= \big(\mathbf{1}^T\bp|_J(t) - \mathbf{1}^T\bp_J(t)\big) + \big(1 - \mathbf{1}^T\bp|_J(t)\big) \\ &= 1 - \mathbf{1}^T\bp_J(t). \end{align} \] The zero-padded FSP approximation is a subprobability vector, so the familiar identity between total variation distance and half the \(1\)-norm for two probability vectors does not apply directly. With the convention \(d(\mu,\nu)=\sup_B|\mu(B)-\nu(B)|\), its discrepancy from the exact distribution is the full leaked mass. A comparison of two probability distributions requires specifying how the missing mass is represented, for example by an absorbing sink.

The certificate concerns the exact solution of the finite subgenerator equation. A numerical approximation to that solution introduces an additional propagation error. If that error is bounded by \(\varepsilon_{\rm num}\) in the \(1\)-norm, the triangle inequality adds it to the truncation discrepancy. The truncation certificate should therefore not be presented as a complete error bound for an arbitrary numerical propagator (Munsky and Khammash 2006).

WarningExercise

(FSP 1-norm leakage bound derivation) Consider a CTMC with generator \(\bA\) partitioned into retained set \(J\) and complement \(J^c\).

  1. Prove that \(\mathbf{1}^T\bA_J \leq \bzero^T\) elementwise, with strict inequality for at least one entry if transitions from \(J\) to \(J^c\) exist.

  2. Show that \(\frac{d}{dt}\big(\mathbf{1}^T\bp_J(t)\big) \leq 0\), confirming that total modeled probability mass decreases monotonically over time.

  3. Let \(\varepsilon=1-\mathbf{1}^T\bp_J(T)\). Verify from the referenced result that the zero-padded FSP error is exactly \(\varepsilon\) in the \(1\)-norm. Explain what additional identification of omitted states would be needed before comparing an absorbing sink with the exact distribution.

33.5 Truncation Strategy: Probability Flux versus Probability Mass

TipRemark

(Failure of instantaneous mass truncation) A naive heuristic for expanding or pruning states in the FSP retains states where the instantaneous probability \(p_i(t)\) exceeds a threshold \(\varepsilon\). In multiscale or stiff reaction networks, this heuristic can discard a low-mass intermediate that carries substantial probability flux and thereby produce an order-one error.

NoteDefinition: Probability Flux

For a transition from state \(j\) to state \(i\) with rate \(A_{ij} > 0\), the instantaneous probability flux at time \(t\) is \[ \begin{align} \Phi_{ij}(t) = A_{ij} p_j(t). \end{align} \] The cumulative probability flux entering state \(i\) over the time interval \([0, T]\) is \[ \begin{align} F_i(T) = \int_0^T \sum_{j \neq i} A_{ij} p_j(s)\, ds. \end{align} \]

TipRemark

(Transient intermediate states) Consider a reaction cascade \(S_1 \xrightarrow{k_1} S_2 \xrightarrow{k_2} S_3\) with \(k_2 \gg k_1\). State \(S_2\) has a rapid exit rate, so its instantaneous probability is tiny: \(p_2(t) \approx \frac{k_1}{k_2} p_1(t) \ll 1\). Pruning based on instantaneous mass \(p_2(t) < \varepsilon\) deletes \(S_2\) from the state space. However, every reaction producing \(S_3\) must pass through \(S_2\). Deleting \(S_2\) severs the probability flow entirely, causing an \(\mathcal{O}(1)\) error in \(p_3(T)\).

Robust adaptive FSP algorithms monitor cumulative probability flux rather than instantaneous probability mass. A state may have negligible instantaneous mass yet carry substantial probability flux across the network.

WarningExercise

(Simulation of a birth–death process) Consider the reactions \(\emptyset\to X\) with propensity \(k_1\) and \(X\to\emptyset\) with propensity \(k_2x\), started from \(x=0\). Implement the referenced result, and compare the histogram of \(X(T)\) over \(10^4\) trajectories with the Poisson distribution of mean \((k_1/k_2)(1-e^{-k_2T})\). Then assemble the generator on the states \(0,...,n_{\max}\) by the referenced result, compute \(e^{T\bA}\be_1\), and compare all three distributions.

WarningExercise

(Detailed balance) Consider the column-stochastic matrix \[ \begin{align} \bP=\begin{pmatrix}0.6&0.2&0\\0.4&0.5&0.1\\0&0.3&0.9\end{pmatrix}. \end{align} \] Find its stationary distribution \(\boldsymbol{\pi}\), verify detailed balance on each edge, and compute \(\bS = \bD_{\boldsymbol{\pi}}^{-1/2}\bP\bD_{\boldsymbol{\pi}}^{1/2}\). Verify directly that \(\bS\) is symmetric and that the eigenvalues of \(\bP\) are real.

WarningExercise

(Probability mass versus cumulative flux in stiff cascades) Consider the three-state continuous-time Markov chain \[ \begin{align} X_1 \xrightarrow{k_1} X_2 \xrightarrow{k_2} X_3 \end{align} \] with \(k_1 = 1\), \(k_2 = 10^4\), and initial condition \(\bp(0) = (1, 0, 0)^T\).

  1. Solve the system analytically for \(p_1(t), p_2(t), p_3(t)\).

  2. Show that \(\max_{t \geq 0} p_2(t) \approx 10^{-4}\). If a threshold \(\varepsilon = 10^{-3}\) is used to prune states by instantaneous mass, state \(X_2\) is discarded at all times.

  3. Compute the cumulative flux \(\int_0^T k_1 p_1(s)\, ds\) entering \(X_2\) for \(T = 3\). Show that over \(95\%\) of the total system probability passes through \(X_2\) despite its negligible instantaneous mass.

  4. Explain why adaptive truncation based on cumulative probability flux preserves state \(X_2\) while mass-based thresholding disconnects the state space.

WarningExercise

(Birth–death process and infinite generator truncation) For a simple birth–death process with birth rate \(\lambda\) and death rate \(\mu x\), write down the tridiagonal subgenerator \(\bA_J\) for copy numbers \(x \in \{0, 1, ..., N\}\). Formulate the exit rate from boundary state \(N\) and derive the leakage rate \(\frac{d}{dt}\mathbf{1}^T\bp_J(t)\) as a function of \(p_N(t)\).
